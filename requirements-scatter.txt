# Optional dependency: torch-scatter
#
# Required for frame-field / polygon-related features
# (pytorch_segmentation_models_trainer.custom_losses.crossfield_losses,
#  tools.polygonization.*, etc.)
#
# torch-scatter is NOT on PyPI — it must be installed from the PyG wheel index
# matching your installed PyTorch version:
#
#   pip install torch-scatter -f https://data.pyg.org/whl/torch-<VERSION>+<DEVICE>.html
#
# Examples:
#   PyTorch 2.4.1, CPU-only:
#     pip install torch-scatter -f https://data.pyg.org/whl/torch-2.4.1+cpu.html
#
#   PyTorch 2.4.1, CUDA 11.8:
#     pip install torch-scatter -f https://data.pyg.org/whl/torch-2.4.1+cu118.html
#
# To install everything at once (base deps + scatter):
#   pip install -r requirements.txt
#   pip install torch-scatter -f https://data.pyg.org/whl/torch-$(python -c "import torch; print(torch.__version__)")+cpu.html
#
# Without torch-scatter, all base features work normally.
# Only frame-field crossfield loss computation will raise ImportError at runtime.
